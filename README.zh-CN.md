我近期很多项目都在本地或私有环境中，因为它们具备较强的公司业务属性。这里用架构和结果描述，不暴露内部业务细节。

这些项目大量借助 AI coding 完成实现，但产品定义、架构拆解、流程设计和核心业务逻辑由我主导。

## 我如何使用 AI coding

- 从业务流程出发，而不是从 prompt 出发。
- 把模糊需求拆成 schema、接口、状态机和可测试的服务边界。
- 使用 Codex、Claude Code 等工具加速实现、重构、文档和验证。
- 保留关键判断在人这里：架构、边界条件、安全边界、部署约束和业务逻辑。
- 更偏好交付真实可用的内部工具和具备生产形态的 demo，而不是孤立的 AI 实验。
